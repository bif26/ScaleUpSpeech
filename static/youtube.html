YouTube Helper

Shadow what people say in YouTube videos. The browser extension captures the captions and pipes them here.

How it works

  1. Install the LanguageShadow extension (Manifest V3, Chrome/Chromium/Firefox compatible).
  2. Open any YouTube video that has captions (auto or manual).
  3. Click the extension icon and toggle "Send captions to LanguageShadow".
  4. Come back to this page — the latest captions appear below.
  5. Click "Use as reference" to load them into the Read Text mode, then speak along with the video.

No audio is uploaded. The extension only reads the on-screen caption text, sends it to 127.0.0.1:8765, and LanguageShadow stores the last 50 lines locally in your browser.

Extension installation

  1. Open chrome://extensions (or about:addons in Firefox, then "Debug Add-ons").
  2. Enable Developer mode.
  3. Click "Load unpacked" and select the extension/ folder inside LanguageShadow.
  4. The extension should appear in your toolbar.
